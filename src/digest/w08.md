- Transfer ladder p34-35: (1) direct feature reuse (no training; NN search, clustering, retrieval; few/no labels; cannot reshape representation) (2) linear probing / train head, frozen backbone (3) partial fine-tuning (later layers; domain differs, moderate data) (4) full fine-tuning (enough data, big domain gap; compute & overfitting risk) (5) from scratch (no suitable pretrained model, unusual modality, huge dataset). Fewer labels/compute -> frozen; more data + larger domain gap -> fine-tune; more fine-tuning not automatically better (small data can destroy features/overfit); linear probe diagnostic (good -> representation already contains info).

- ViT p65-77: break image into patches; linear projection to patch embedding; attention: each token -> query, key (W_k: "what I contain", for matching), value (W_v: message); score q·k (wheel example 2.4, 2.1, 0.8, −0.5); softmax -> weights sum to 1 (0.34, 0.29, 0.15, 0.08, 0.03); message z_i = Σ_j a_ij v_j; residual x'_i = x_i + z_i; matrix form S = QKᵀ (softmax(QKᵀ/√d)V); multi-head; transformer layer (attention + MLP + norms + residuals), stacked.

## ViT paper (Dosovitskiy et al., ICLR 2021, "An Image is Worth 16x16 Words", P08)
- Split image x ∈ R^{H×W×C} into N = HW/P² flattened patches (P=16 -> 224²: 196 patches), trainable linear projection to D dims (patch embeddings); prepend learnable [class] token z_0^0; its output z_L^0 (after LayerNorm) = image representation y; classification head MLP (one hidden layer) at pre-training, single linear layer at fine-tuning; learnable 1D position embeddings (2D-aware gave no significant gain); Transformer encoder (MSA + MLP, LayerNorm, residuals).
- Inductive bias (Sec 3.1): CNNs bake in locality, 2D neighbourhood structure, translation equivariance in every layer; ViT: only MLPs local & translation-equivariant, self-attention global; 2D structure used sparingly (patch cutting; position-embedding interpolation at fine-tuning resolution). Position embeddings initially carry no 2D info -> must learn spatial relations from scratch.
- Mid-sized data (ImageNet) without strong regularisation: a few % below comparable ResNets; "large scale training trumps inductive bias". Pretrained on ImageNet-21k or JFT-300M: ViT-H/14 88.55% ImageNet top-1, 90.72% ReaL, 94.55% CIFAR-100.
- Variants (Table 1): Base 12 layers D=768 MLP 3072 heads 12 86M; Large 24, 1024, 4096, 16, 307M; Huge 32, 1280, 5120, 16, 632M. Notation ViT-L/16 = Large with 16x16 patches; smaller patch -> longer sequence -> more compute (quadratic attention).
- Fig 3: pretrained on ImageNet, ViT-L underperforms ViT-B; ImageNet-21k similar; only JFT-300M shows full benefit of larger models (data size matters).
- Tutorial: sequence length vs patch size trade-off (fine detail vs compute ~N²); reuse for detection (DETR), segmentation, depth (DPT), place recognition (DINOv2 features AnyLoc); need task-specific heads/decoders.
