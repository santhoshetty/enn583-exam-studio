# W11 Segmentation & grasp prediction (L11, 44pp)
- Semantic segmentation p4-5: class per pixel; pixel mask supervision; pixel-wise CE; mean IoU. Output C logits per pixel (C×H×W); mutually exclusive -> softmax; non-exclusive -> element-wise sigmoid; prediction argmax_c p_c(i,j).
- Instance segmentation p6-7: separate mask + label per instance (two cups -> two masks); classification + mask losses; mask AP. Semantic vs instance: semantic doesn't separate instances.
- Dense prediction (depth too) p8-9: output size = input size but encoder features smaller (e.g. H/8×W/8) -> encoder–decoder p10: downsampling (pooling, strided conv) / upsampling (unpooling, transposed conv) p12. U-Net skip connections p13: copy high-resolution low-level encoder features to decoder -> preserve boundaries & detail.
- Mask R-CNN p15 (Faster R-CNN + mask head). SAM promptable segmentation p16 (points/boxes prompts), SAM3 open-vocabulary segmentation p17. Models p18: DeepLabv3/v3+ (CNN), Mask2Former, SegFormer (transformer), SAM2/SAM3 (promptable foundation).
- Grasp prediction p22-41: top-down (planar) vs 6-DoF. Planar grasp (x, y, θ, w, q): centre in image, in-plane gripper orientation, opening width, quality p23. 6-DoF (x,y,z, φ,θ,ψ, w, q) p24. Inputs: depth/point cloud in addition to RGB p25. Data p26: human labels (Cornell), simulation (Jacquard), real RGB-D + analytic grasps (GraspNet-1Billion).
- Generative (generate grasp from visual data) vs discriminative (rate a proposed grasp: "90% chance of success") p27-28. Discriminative Dex-Net 2.0 p30: slow, cost grows with number of candidates. Generative multi-grasp as detection (Faster R-CNN-like, multiple grasps per image) p31; GG-CNN p32 dense per-pixel prediction (angle, width, quality per pixel), like segmentation, real-time reactive.
- Top-down limited p33: fixed approach direction, can't exploit arbitrary 3D surfaces. Contact-GraspNet p34 (per-point contact classification + remaining params). AnyGrasp p35 practical pretrained 6-DoF detection & tracking in clutter. Diffusion p36: many valid grasps (multi-modal) -> learn distribution, refine noisy poses iteratively, diverse candidates, then rank/filter by quality & collision (GraspGen p37). Semantic/task-aware p38-40: geometry-only "where can I grasp?" vs language-conditioned "what & how for the task?" (GraspMolmo, GraspVLA). Start with p41: AnyGrasp (practical), GraspMolmo/GraspVLA (language), Contact-GraspNet (understanding), GraspNet-1Billion (dataset).
- Exam Q26: per-pixel class logits + CE + mean IoU; Q33: imbalance (background dominates unweighted loss); Q34: IoU = |P∩G|/|P∪G|.
## Contact-GraspNet (Sundermeyer, Mousavian, Triebel, Fox, ICRA 2021, P11)
- Motivation: prior 6-DoF pipelines are complex sequential multi-stage (segment object -> generate grasps on isolated object cloud -> learned collision filtering, Murali et al. [12]) -> issues: (1) sensitivity to instance segmentation errors; (2) no geometric scene context (table, neighbours) for collisions; (3) prediction in large unconstrained 6-DoF pose space. Also run-times unsuitable for closed-loop; planar grasping needs perpendicular view, neglects kinematics.
- Representation: treat observed 3D points as potential contacts c; grasp t_g = c + (w/2) b + d a, R_g = [b, a×b, a] with approach a, baseline b (unit vectors), d constant baseline-to-gripper-base distance -> learning reduced to 4-DoF (3-DoF rotation + width) per contact point plus contact confidence; no ambiguities/discontinuities; sampling contacts covers grasp modes.
- Full scene point cloud (or local region crop) -> collisions considered during generation; segmentation optional afterwards to pick target grasps; robust to under-segmentation (Fig 7 driller).
- Network: PointNet++ asymmetric U-shaped; heads for contact confidence, approach, baseline, width bins (weighted width-bin loss crucial; otherwise collapse to narrow widths); add-s loss improves high-confidence contacts.
- Training data: ACRONYM (8872 ShapeNet meshes, 17.7 million simulated parallel-jaw grasps), objects placed at stable poses in random scenes; class-agnostic; noise injection σ=0.001 helps real sensor generalisation. Training on small dataset (110 objects, 5 categories) insufficient.
- Real robot: Franka Panda, 9 cluttered scenes, 51 unseen objects, RealSense L515; max 2 trials. Table I: 6-DOF GraspNet 62.7% success; +CollisionNet [12] 80.39% success, 68.63% first attempt, 67 attempts; Contact-GraspNet 90.20%, 84.31%, 59 attempts ("over 90%, cutting failure rate in half"). Run time 0.28 s full scene, ~0.19 s local region.
- Sim metrics: success (no collision of open gripper + object held after shaking) & coverage (% GT grasps within 2 cm of a generated grasp). Ablations: local regions raise coverage; full scene similar success but lower coverage.
- Failure cases: thick objects needing near-max width; small objects low-confidence contacts.
