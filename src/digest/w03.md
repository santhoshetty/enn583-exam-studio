# W3 Cameras & stereo (L03, 107pp)
- Pinhole p13-18: aperture, focal length, optical axis; similar triangles x/f = X/Z -> x = fX/Z, y = fY/Z (image inverted behind; virtual image plane in front).
- Central projection p21-22: homogeneous [[f,0,0,0],[0,f,0,0],[0,0,1,0]]·[X,Y,Z,1]^T = (fX, fY, Z) -> divide by 3rd: (fX/Z, fY/Z).
- Pixels p25-26: u = x/ρu + u0, v = y/ρv + v0 (ρ pixel size, (u0,v0) principal point; origin top-left). Matrix [[1/ρu,0,u0],[0,1/ρv,v0],[0,0,1]].
- Complete model p27: p̃ = K [f-projection] · (ξC)^-1 · P; K intrinsic (f/ρ, u0,v0), (R,t)^-1 extrinsics (camera pose inverted: world->camera). Camera matrix C 3x4 p28; u=ũ/w̃. Scale invariance p29: λC gives same pixel -> normalise C34=1 -> 11 DOF (focal length, pixel size, principal point, position, orientation) p30.
- p32 no unique inverse (lost depth; infinitely many 3D worlds). p33 perspective: lengths/angles not preserved; parallelism, perpendicularity lost; straight lines stay straight. p34 vanishing points (parallel lines meet, can be outside image), vanishing lines (parallel planes).
- Bayer p35: RGGB, 2x green (luminance, human sensitivity), demosaicing interpolation. Shutter p36-37: global (all pixels simultaneously, no skew, costly) vs rolling (rows sequential, skew moving objects, cheap).
- Aperture p40: large -> blur; pinhole -> little light -> long exposure -> motion blur; too small -> diffraction. Lenses p42: rays via optical centre undeviated; parallel rays -> focal point. Thin lens 1/f = 1/Z + 1/e p45. Blur circle R = Lδ/(2e) p47 (L aperture diameter, δ focus offset); keep R < 1 pixel. Pinhole approx p48-51: Z>>f, Z>>L -> e≈f -> x = fX/Z (perspective projection).
- Stereo p53-64: disparity d = uL - uR ∝ fb/Z; right image points shift left; distant points shift less p57-58. Simplified case identical aligned cameras vs general p59. Block matching along row p60 (search up to dmax). Triangulation p62-63 (identical cams aligned on x): Z = b f/(uL - uR), X = Z uL/f, Y = Z vL/f (u,v relative to principal point, f in pixels).
- Baseline p64: large baseline -> small depth error, but larger minimum measurable depth and harder search for close objects; small baseline -> larger depth error, smaller min depth, easier search. Depth error grows ~Z² (δZ ≈ Z²/(fb) δd).
- Rectification p66-67, p96-104: warp both images by homographies H_L, H_R so image planes coplanar & parallel to baseline, same K̂ (avg of KL,KR) and R̂ (r1 = baseline direction, r2 = r3L × r1, r3 = r1×r2) -> epipolar lines horizontal scanlines -> search same ROW. First undistort lens distortion, then homographies, bilinear interpolation.
- Calibration p68-93: planar target Z=0 -> 3x3 homography H (8 DOF, 4 points) p72, H = R + t nᵀ/d (plane-induced). DLT p89: each point 2 equations, stack Q h = 0, solve SVD. Zhang: B = K^-T K^-1, constraints from r1,r2 orthonormal, Cholesky -> K; "Won't be asked at the exam" (p92 details).
- Lens distortion p94: radial barrel, pincushion, fisheye.
- Recap questions p106.
