# W10 Object detection & open-vocabulary (L10, 94pp)
- Task p9: input RGB; output SET of boxes + class labels + confidences; supervision box+label per object; loss classification + box regression; metric AP at IoU threshold. Output per object p10: (x_min,y_min,x_max,y_max) + class score distribution.
- Key challenge p13: variable number of objects (classification/segmentation fixed output size). Candidates from p14: (1) two-stage: anchors + region proposal network; (2) anchor-based one-stage; (3) anchor-free/point-based; (4) transformer: learned object queries.
- Two-stage (Faster R-CNN) p15-28: modular, reliable baseline, easy fine-tuning, in Detectron2/MMDetection/TorchVision; descendants Mask R-CNN (+masks), Cascade R-CNN (progressive refinement), Sparse R-CNN. Stage 1: dense grid of anchors (location, scale, aspect ratio; 3 scales × 3 ratios per sliding-window location); RPN predicts objectness + box regression; take top-N (e.g. 1,000) proposals. Stage 2: RoI pooling (different-size regions -> same-size features) -> detector head: class distribution incl. background + refined box.
- Post-processing p31-33: discard low-confidence; remove duplicates with Non-Maximum Suppression (keep highest-score box, suppress others with IoU > threshold with it). DETR-style generally no NMS (one-to-one matching).
- One-stage p35-42: anchor-based (SSD, RetinaNet, EfficientDet; less dominant now); point-based (every pixel predicts class scores + box geometry: FCOS, CornerNet, CenterNet; current YOLOv8, YOLO11, RTMDet). FCOS: anchor-free & proposal-free -> no anchor hyperparameters/overlap computation; per-pixel class scores × centerness -> centerness-aware scores; per-pixel box regression (distances to box sides); threshold.
- DETR p44-47: predict fixed-size set of object hypotheses. Table p46: one-stage anchors/points, thousands of candidates, many duplicates, NMS, local dense prediction vs DETR object queries, small fixed set, one-to-one, typically no NMS, global attention/set prediction. Original issues: slow convergence, small objects, global attention cost. Variants: Deformable DETR (sparse/deformable attention, multi-scale, faster convergence), DINO (2022; query init, denoising training; anchor-like reference boxes), RT-DETR (2023, real-time, no NMS), RT-DETRv3...
- Training p49-53: detection = classification + localisation + assignment (which prediction responsible for which GT). Classification loss: CE/softmax, BCE/sigmoid, focal loss for imbalance. Box loss: L1 or IoU-based 1−IoU, GIoU, DIoU, CIoU (coordinate closeness vs overlap). Objectness loss (RPN, YOLO). Class imbalance: thousands of candidates mostly background; easy negatives dominate -> sampling, focal loss (down-weight easy examples), DETR one-to-one matching.
- Datasets p54: COCO 80 classes; Objects365 365 classes 2M images 30M boxes; OpenImages V7 600 classes 15.9M boxes; LVIS 1200+ long-tail; nuImages driving.
- Evaluation p59-70: IoU = |A∩B|/|A∪B| = I/(A+B−I). TP if IoU ≥ threshold AND correct class AND GT not already detected (higher-score first); rest FP; undetected GT = FN. Precision = TP/(TP+FP) (fraction of detections correct); Recall = TP/(TP+FN) = TP/P (fraction of objects found). Depends on confidence threshold and IoU threshold. PR curve by varying confidence threshold. AP = area under PR curve for one class at one IoU threshold (COCO: sample at 101 recall values, average precision). mAP = (1/k) Σ AP_i over classes. COCO mAP@[0.5:0.95] averaged over IoU thresholds; mAP@0.5. Caveats p69: AP summarises many thresholds (interpolation) - two detectors similar at deployed threshold can differ in AP; mAP penalises low recall strongly; IoU may be stricter than task needs; mAP weights classes equally. Robotics also: recall at fixed FP rate, latency, distance-dependent recall, safety-critical classes p70.
- Open set / open vocabulary p73-87: closed-set training (fixed list, COCO 80); deployment meets unseen objects -> common failure: classify novel object as known class. Closed set (choose among known), open set (detect known + flag unknown), open vocabulary (detect objects from arbitrary text descriptions). CLIP: image and text encoders with shared embedding space; similarity = "does image match concept?", detection needs "where?" -> propose regions/queries and score against text embeddings; prediction head conditioned on language. Grounding DINO (DETR/DINO set prediction; image+text features; queries aligned to phrases; vocabulary changeable at inference). Prompts matter p85: prompt changes which objects, labels, confidences; synonyms; more specific not always better; prompt design = system design. Limits p86: visual difficulty (small, occlusion, viewpoint, domain shift), language difficulty (ambiguity, synonyms, fine-grained, prompt sensitivity), attributes/state ("empty cup"), relations/affordances ("cup next to laptop", "something I can grasp") -> open vocab ≠ open-ended reasoning. Others: OWL-ViT/OWLv2, GLIP, YOLO-World, YOLOE.
- Practical p89-92: start simple with strong pretrained baseline (Faster R-CNN) and fine-tune; libraries TorchVision, MMDetection, Hugging Face, Detectron2; choose confidence threshold for what matters (high recall for safety-critical; high precision if false detections trigger costly actions); analyse error types.
- Exam Q31: IoU = 30/(60+50−30) = 0.375; Q32 AP across thresholds vs one operating point; Q27 lower threshold -> fewer missed hazards, more unnecessary stops.
## DETR (Carion et al., ECCV 2020, P10)
- Detection as direct set prediction; removes hand-designed components: anchor generation and NMS. Architecture (Fig 2): CNN backbone (ResNet-50) -> transformer encoder (with positional encodings) -> decoder with N = 100 learned object queries -> shared FFN per query predicts (class incl. ∅ "no object", box centre/height/width normalised). Baseline 6 enc + 6 dec layers, width 256, 8 heads, 41.3M params (23.5M ResNet-50, 17.8M transformer).
- Bipartite matching (Eq 1): σ̂ = argmin_σ Σ L_match(y_i, ŷ_σ(i)), GT padded with ∅ to size N; Hungarian algorithm; L_match = −1{c≠∅} p̂(c) + 1{c≠∅} L_box. Hungarian loss (Eq 2) = Σ [−log p̂(c_i) + 1{c≠∅} L_box], ∅ log-prob term down-weighted by 10 (class imbalance). L_box = λ_iou GIoU loss + λ_L1 ||b − b̂||₁ (L1 alone scale-dependent; GIoU scale-invariant). Unmatched queries are trained to predict ∅.
- One-to-one matching => each object predicted once => no NMS needed (duplicates penalised).
- Table 1 (COCO val; GFLOPS/FPS, params, AP, AP50, AP75, APS, APM, APL): Faster RCNN-FPN+ 180/26, 42M, 42.0, 62.1, 45.5, 26.6, 45.4, 53.4; DETR 86/28, 41M, 42.0, 62.4, 44.2, 20.5, 45.8, 61.1; DETR-DC5 187/12, 41M, 43.3, 63.1, 45.9, 22.5, 47.3, 61.1. DETR vs FPN+: APL +7.8, APS −5.5 (global self-attention helps large objects).
- Training long: baseline 300 epochs on 16 V100; 500 epochs for comparison schedule (vs Faster R-CNN 9x schedule ~109 epochs... use "much longer").
- Table 4 loss ablation: class+L1 only AP 35.8 (−4.8); class+GIoU 39.9 (−0.7); both 40.6 baseline. Limitations: training/optimisation, small objects; fixed N caps max detections (Fig: 100 slots).
