# W6 Robust losses, pose graphs, BA, factor graphs, MAP (L06, 110pp)
- Recap p4-12: templates (parameters/prediction/residual/objective) for scale recovery, PnP, 3D-3D (residual = Euclidean 3D distance). Keyframes.
- PTAM tracking p17-21: parameters R,t as vector μ; prediction with lens distortion; residual reprojection; objective Tukey biweight.
- M-estimators p22-24: Huber quadratic → linear for |r|>k (k=1.345 common); Tukey quadratic then flattens to constant, influence zero beyond cutoff (4.685). Categories p23: unbounded influence (quadratic: outliers dominate); bounded (L1, Huber, pseudo-Huber, Fair); redescending (Tukey, Cauchy, Hampel, Welsch, Andrews); finite rejection point (Tukey, Hampel, Andrews: zero influence beyond threshold). "Influence" = how strongly an observation pulls the model. L1 -> median-like; squared -> mean.
- Pose graph p33-39: relative motions between consecutive AND non-consecutive frames. Inconsistency: x0Tx1·x1Tx2 ≠ x0Tx2; differing confidences. X* = argmin_X Σ ||x_i − ^iT_j · x_j||² (difference between SE(3) poses - not a simple minus). Nodes = poses (variables); factors = relative-pose measurements.
- BA p40-45: variables = poses x_i AND 3D points p_j; P*,X* = argmin Σ_{i,j} ||y_j^i − π(p_j, x_i, K)||² (reprojection error of j-th landmark in i-th camera). Sliding-window BA: only last n frames (graphs grow).
- Solving p47-59: closed form for simple f (f=3x²+5(x+3) -> f'=6x+5=0 -> x=-5/6). Complicated nonlinear vector problems -> iterative: gradient descent; Gauss–Newton (JᵀJ Δx = −Jᵀ r); Levenberg–Marquardt (JᵀJ + λI)Δx = −Jᵀ r interpolates GN (fast local convergence) and gradient descent (cautious). Normal equations AᵀA x = Aᵀb; Jacobian sparse (each measurement touches few variables) -> efficient. Spring-mass analogy p56 (solution = minimum energy). Multiple minima p57; solution depends on initial guess p58; must be close; vulnerable to outliers; software gtsam, Ceres, SymForce (autodiff Jacobians) p59.
- Probabilistic estimation p63-73: variables vs observations/priors; sensor fusion. Gaussian (μ,σ²) 1D; multivariate μ, Σ (ellipses). Kalman example p71: prior → prediction p(x|u) (more uncertain) → posterior p(x|u,z) closer to the more certain measurement. p(z|x) measurement likelihood = sensor model. Full smoothing p(x0..xt|u,z) vs filtering p(xt|u,z) vs recursive p(xt|x_{t-1},u_{t-1},z_t) p84.
- Factor graphs p74-83: variable nodes (unknowns) + factor nodes (probabilistic constraints from measurements/priors); bipartite, undirected (every edge variable–factor). Examples: GPS unary factors; + VO binary factors; pose graph SLAM with loop closure; SLAM with landmarks; BA; switchable constraints (Sünderhauf).
- Factorisation p86: joint = Π p(x_i|x_{i-1},u_{i-1}) · Π p(x_j|z_j) – these are the factors.
- MAP vs distribution p89-90: x* = argmax p(x|…) (MAP); full distribution keeps mean+variance (uncertainty); MAP easier but loses uncertainty (recoverable later at higher cost). Same MAP can hide different spreads -> different decisions (Q25).
- Derivation p97-107: assume Gaussian factors p ∝ exp(−½ eᵀ Σ⁻¹ e), e = x_i − ^iT_j·x_j; constant dropped; log (monotonic) turns product into sum; Mahalanobis distance ||e||²_Σ = eᵀΣ⁻¹e (Euclidean scaled by uncertainty); maximise −½Σ -> minimise Σ ||e||²_Σ => MAP = weighted nonlinear least squares. Scalar: contribution (r/σ)²; σ=0.5 vs 1.0 -> 4x (Q23).
