# W13 When deep learning fails (L13, 52pp)
- Cost of mistakes annoying -> life-threatening p4. Closed-set training vs open-set/OOD deployment p5-9; typical failure: unknown objects confidently misclassified as known classes (Fishyscapes) p8; condition changes -> feature changes (OOD) p9.
- Definitions p10: OOD = input from different distribution than training (p_train(x) very small/zero); open-set recognition = test classes unseen in training, recognise as unknown; open-world = detect unknowns then learn/incorporate new classes over time. OOD need not be a novel class (known class in heavy fog / new sensor); open-set specifically unknown classes.
- Core assumption p11: p_train(x,y) = p_deploy(x,y). Shift types p12: covariate shift p(x) changes, p(y|x) same (lighting, weather, camera, corruption); label/prior shift p(y) changes, p(x|y) same (class frequencies change); concept shift p(y|x) changes (mapping appearance->label changes); novel classes/open set: ∃(x,y*) with p_train=0, p_deploy>0.
- Why confidence matters p13: used to fuse sensors/models, decide trust, trigger fallback/human, weight measurements; miscalibration -> systematically wrong decisions. Softmax looks like probability but not guaranteed.
- Three questions p14: failure/risk estimation ("should robot trust this prediction?", decision-centric); OOD detection ("how unfamiliar is input?", data-centric); uncertainty estimation ("how unsure is the model?", model-centric).
- Calibration p17-21: ideal: n% of predictions with n% confidence correct (80% of "dog @80%" are dogs). Reliability diagram: bins, mean accuracy per bin vs confidence; bin below diagonal (accuracy < confidence) = overconfident; above = underconfident. Modern nets accurate but poorly calibrated (overconfident) p20. Temperature scaling p21: p_i = exp(z_i/T)/Σ exp(z_j/T); single scalar T learned on held-out validation; T>1 softens (fix overconfidence), T<1 sharpens; argmax unchanged (class doesn't change); cheap; calibration on in-distribution val may not hold under shift. ECE (not on slides) = Σ (n_b/N)|acc_b − conf_b|.
- Confidence alone p22: max softmax/detector score is surprisingly good baseline -> reject low max confidence or high entropy; but networks confidently wrong under shift; calibrated confidence still not a reliable OOD detector.
- Uncertainty p30-35 (Kendall & Gal): epistemic = lack of knowledge, reducible with more data; aleatoric = noise inherent in observations, irreducible with more data. Aleatoric learned loss p31: L = (1/D) Σ_i ||x_i − x̂_i||²/(2σ_i²) + ½ log σ_i²: down-weights error for high σ but penalises high σ. Estimation p32-35: predictive entropy H(p) = −Σ p_c log p_c (peaky = low); deep ensembles (train multiple models from different inits, average; disagreement = uncertainty, esp. epistemic); MC dropout (dropout at test time, multiple stochastic passes; disagreement). Can be high for in-distribution ambiguous images.
- OOD detection p38-40: input-centric (atypical vs training): max softmax baseline; feature-space distance to training examples/class prototypes; energy score E(x) = −log Σ_c exp(z_c(x)) on logits (softmax discards absolute logit scale; same softmax confidence can have very different energy; low energy = in-distribution evidence). p41: OOD can be correct; in-distribution can be wrong; high uncertainty, OOD, failure related but NOT identical.
- Decision making p43-47: perception -> prediction + confidence/uncertainty/OOD -> estimated risk -> action. Low reliability: abstain, safe fallback, ask human, stop/defer; persists: collect data, adapt/retrain; high: act; uncertain: slow down, gather another observation, change viewpoint, temporal evidence, another sensor/model. "Uncertainty is only useful if it changes behaviour." Selective prediction p45: if r(x) < τ predict else abstain; coverage = fraction of inputs predicted; (selective) risk = error rate on accepted predictions; lower coverage can give lower risk; risk–coverage curve p46. No universal threshold p47: depends on consequence, reversibility, extra info availability, time, recoverability; warehouse classification accept moderate; grasp -> acquire another view/replan; obstacle detection -> favour high recall; autonomous driving -> slow/stop/hand over.
- Exam: Q38 bin conf 0.60, 8/10 correct -> accuracy 0.80 -> underconfident by 0.20; Q39 coverage 40/50 = 0.80, selective risk 4/40 = 0.10; Q40 test set must stay independent (use validation for thresholds); Q28 aggregate accuracy insufficient (rare-class recall, latency).
## Kendall & Gal, "What Uncertainties Do We Need in Bayesian Deep Learning for Computer Vision?" NeurIPS 2017 (P13)
- Fig 1 CamVid: aleatoric high on object boundaries and distant objects; epistemic high for semantically/visually challenging pixels (failure on footpath with high epistemic, not aleatoric).
- Epistemic = model uncertainty, ignorance about which model generated data, explained away with enough data. Aleatoric: homoscedastic (constant across inputs) vs heteroscedastic (input-dependent; e.g. featureless wall in depth regression -> high). Big-data vision: aleatoric most important to model; but aleatoric alone misses out-of-data examples.
- Epistemic via MC dropout (Sec 2.1): dropout before every weight layer during training AND at test time; T stochastic forward passes sample approximate posterior q(W) (variational inference minimising KL to p(W|X,Y)); predictive variance from sample spread; 50 MC samples used.
- Heteroscedastic regression (Sec 3.2): network outputs ŷ and σ²; loss (1/D)Σ ½ exp(−s_i)||y_i − ŷ_i||² + ½ s_i with s = log σ² (numerically stable); = learned loss attenuation (like robust regression); high predicted uncertainty reduces residual's effect; log σ² term stops predicting high uncertainty everywhere; low σ² with large residual is penalised. Classification (3.3): Gaussian noise on logits, MC integration -> attenuation for classification.
- Combined model achieves SOTA on segmentation (CamVid, NYUv2) and depth (Make3D, NYUv2).
- Table 3(b) classification (train -> test, IoU, aleatoric entropy, epistemic logit variance ×10⁻³): CamVid/4 -> CamVid 57.2, 0.106, 1.96; CamVid/2 -> CamVid 62.9, 0.156, 1.66; CamVid -> CamVid 67.5, 0.111, 1.36; CamVid/4 -> NYUv2 –, 0.247, 10.9; CamVid -> NYUv2 –, 0.264, 11.8. => epistemic falls with more data, rises sharply OOD; aleatoric roughly constant with data size (paper claims also not increasing OOD — note in this table aleatoric roughly doubles on NYUv2, a nice critical-reading point).
- Sec 5.3: DenseNet 640×480 in 150 ms on Titan X; aleatoric negligible extra cost; epistemic MC dropout ~50× slow-down for 50 samples.
- Conclusions: aleatoric important for large data (epistemic explained away) and real-time (no MC sampling); epistemic important for safety-critical (detect unseen situations) and small datasets. Not mutually exclusive; combining best.
