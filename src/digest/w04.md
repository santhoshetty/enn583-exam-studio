# W4 Epipolar geometry, F, E, RANSAC (L04, 90pp)
- Setup p14: two views, unknown R,t (even unknown K) — still a relation between points.
- Back-projected ray of x in cam1 projects to a LINE in cam2: epipolar line l' p20-25. Depends on relative geometry, not on unknown depth.
- p27 epipolar plane = (X, C, C'); epipolar lines = intersection with images; epipole = projection of other camera centre = baseline ∩ image plane. All epipolar lines pass through the epipole. Ideal stereo (p28): epipolar lines horizontal/parallel, epipoles at infinity -> search along row.
- Fundamental matrix p32: l' = F x; x'ᵀ l' = 0 ⇒ x'ᵀ F x = 0 for every correspondence. F 3x3, rank 2, 7 DOF (scale + det=0).
- 8-point algorithm p33-34: each correspondence = one linear equation in 9 entries of f: A f = 0; ||f||=1; SVD, last row of Vᵀ; reshape; enforce rank 2 by second SVD (zero smallest singular value); Hartley normalisation then denormalise F = T'ᵀ F̃ T. (Slide p33 typo says findHomography(); correct OpenCV is findFundamentalMat.)
- Degenerate p35: pure rotation (no translation/epipoles), planar scene (H fits, F not unique), collinear/clustered points; near-degenerate: very small baseline, distant points (weak parallax), forward motion near epipole, dynamic scene, lens distortion/rolling shutter violate pinhole model. Checks p36: inlier count/ratio, spatial distribution, H vs F comparison, Sampson error, cheirality (points in front of both cameras), resampling stability, temporal consistency. OpenCV returns a matrix even for degenerate data.
- Match checking p40-42: x'ᵀFx = 0 -> correct (in practice |error| < threshold, e.g. distance to epipolar line / Sampson). Chicken-and-egg -> RANSAC.
- RANSAC (Fischler & Bolles 1981) p43: (1) model from random minimal set (2) error vs all data (3) inliers error<threshold (4) repeat k times (5) best = biggest inlier set (largest consensus). Line fit example: 2 points p52. For F: 8 pairs p54.
- Iterations p55-56: k = log(1-p)/log(1-wⁿ) (w inlier ratio, n minimal set size, p success probability that at least one sample all-inlier). Slide numbers: w=90%, n=8, p=99.9% -> k=13; w=75% -> 65 (formula gives 65.5 -> 66 when rounding up; slide shows 65). All-inlier probability wⁿ decreases exponentially in n.
- Variants p57: PROSAC (rank-ordered sampling), LO-RANSAC (local re-estimation of good models), preemptive (reject early), GC-RANSAC (spatial coherence of labels), MAGSAC++ (marginalise over noise scales; less threshold sensitive), USAC (modular framework).
- Essential matrix p61-64: with known K, normalised coords x̂ = K⁻¹x ⇒ x̂'ᵀ E x̂ = 0. ≥5 correspondences (5-point, findEssentialMat). E = K'ᵀ F K. E = [t]× R (normalised cameras [I|0] and [R|t]), [t]× = [[0,-tz,ty],[tz,0,-tx],[-ty,tx,0]]. E has 5 DOF (3 rot + 2 translation direction).
- Decompose p67-69: 4 solutions [R1,t],[R1,-t],[R2,t],[R2,-t] (R1,R2 differ by 180° twist about baseline); triangulate, keep the one with points in front of both cameras (cheirality / positive depth). recoverPose() does all.
- Scale ambiguity p71-72: t only up to scale (direction, not distance); R correct. Unknown s along s·t.
- Use p73-76: initialise monocular VO (R,t from first two frames, triangulate map, arbitrary scale) then switch to 3D-2D PnP. AR (PTAM, Oculus) does not need metric scale. With depth (stereo/RGB-D) recover scale; but with depth better use PnP.
- Recover scale p77-79: s* = argmin_s Σ_i ||x_i^obs − π(K(R p_i + s t))||² — reprojection error, nonlinear least squares (scipy).
- Problem table p80: exact -> solve; noisy linear -> least squares QR/SVD; noisy nonlinear -> Gauss-Newton/LM; outliers -> robust loss or RANSAC.
- Summary p87: detect, match, findEssentialMat, decompose, triangulate (or recoverPose). Outlook 3D-2D (PnP) and 3D-3D p89-90.
- Exam: Q11 epipolar line; Q12 RANSAC works because some minimal samples all-inlier; Q13 threshold 2->5 px: all previous inliers remain inliers, some outliers become inliers; Q14/Q17 monocular scale needs metric info; Q16 largest consensus.
