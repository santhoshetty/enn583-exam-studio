# W9 Learned geometry & 3D representations (L09, 80pp)
- Agenda p3: monocular depth; depth -> learned multi-view geometry; classical 3D reps; learned implicit (Occupancy nets, SDF, NeRF); learned explicit (3DGS).
- Depth map p5,p25: per pixel Z coordinate in camera frame (H×W×1).
- Supervision p6: direct (LiDAR, RGB-D, structured light, stereo, synthetic rendering); self-supervision from geometry (stereo pairs or mono video + motion; predict depth, warp other view, photometric reconstruction error); pseudo-label/teacher (strong pretrained model labels big unlabelled sets, train student).
- Direct p8-10: metric supervision can learn absolute depth; limitation: dense accurate GT depth expensive. Eigen et al quote: monocular depth ill-posed (infinitely many scenes); global scale ambiguity remains (room vs dollhouse) -> scale-invariant error; easier up to global scale -> trend to relative depth.
- Stereo self-supervision p12-13: network predicts disparity from left image; d = D(u,v) -> corresponding right pixel (u−d, v); photometric loss I_left(u,v) − I_right(u−d, v). (Monodepth-style.)
- Depth Anything p18-22: teacher (DINOv2 encoder, supervised) -> pseudo-labels on large unlabelled data -> student; plain self-training gave no gain (same pretraining/architecture -> same errors) -> strong perturbations on unlabelled images (colour jitter, Gaussian blur, spatial distortion/CutMix). V2: teacher trained on synthetic depth (clean, dense, fine detail), larger teacher DINOv2-Giant, students on 62M+ pseudo-labelled real images.
- Pointmap p26: 3D (x,y,z) per pixel (H×W×3). DUSt3R p27-35: unknown poses & intrinsics -> pointmaps; recover camera params, correspondences, depth, 3D reconstruction; works for single image too; up-to-scale (consistent not metric) p28; key shift p29: no explicit 2D matching/E/triangulation; predict dense pointmaps then recover depth, correspondences, pose, focal. Training p32-34: init from Cross-View Completion (CroCo) pretraining, then direct 3D supervision on pairs with GT pointmaps (from depth, synthetic, known poses). >2 cameras p35: pairwise then global alignment optimisation. MASt3R p36: DUSt3R + per-pixel descriptor head for matching; pointmaps metric (loss uses true scale). Summary p39: learned multi-view can replace features→matches→pose→triangulation.
- Classical reps p41-45: occupancy gridmaps, point clouds, voxels, meshes, octrees.
- Occupancy Networks p48-51 (Mescheder 2019): f_θ(x, h) → p_occupied, latent code h from encoder (reuse across objects), surface = decision boundary p=0.5, continuous, arbitrary resolution; trained on sampled points with inside/outside labels.
- DeepSDF p53: f_θ(x,h) → signed distance s (s<0 inside, 0 surface, >0 outside); richer than occupancy (how far).
- NeRF p57-63 (Mildenhall 2020): f_θ(x,y,z,θ,φ) → (σ, R,G,B): density (where content is, geometry implicit) + view-dependent colour. Training: posed images; per pixel cast ray, sample points, query, differentiable volume rendering → predicted pixel colour vs true colour = loss. No GT 3D geometry needed; geometry emerges from multi-view consistency. Representation in network weights (implicit). Block-NeRF large scale; LERF = NeRF + CLIP (language features).
- 3D Gaussian Splatting p70-73: explicit primitives: each Gaussian has mean + covariance (centre, shape), opacity, view-dependent colour via spherical harmonics; render by projecting to 2D ellipses ("splatting") blended by depth & opacity; fast; learned by comparing renders with training images (no GT geometry). LangSplat = 3DGS + CLIP.
- Summary p77-80: classical explicit pipeline features→matches→geometry→pose→3D; geometry now embedded in learned reps/objectives. Representation table p78: point clouds (surface samples), voxels/occupancy (free/occupied), meshes, OccNet/DeepSDF (continuous geometry), NeRF (implicit geometry+appearance), 3DGS (explicit + fast rendering), LERF/LangSplat (+semantics). Best rep depends on task p79: VO/SLAM geometry & consistency; planning free/occupied space; rendering appearance; semantic robotics language-aligned 3D.

## DUSt3R (Wang, Leroy, Cabon, Chidlovskii, Revaud, CVPR 2024, P09)
- 3.1: network f: two RGB images → two pointmaps X^{1,1}, X^{2,1} ∈ R^{W×H×3} + confidence maps C^{1,1}, C^{2,1}; BOTH in coordinate frame of camera 1 (radical difference). Architecture CroCo-inspired: Siamese weight-sharing ViT encoder → two transformer decoders exchanging info via cross-attention → regression heads.
- 3.2 loss: Euclidean 3D regression ||X/z − X̄/z̄|| with normalisation by average distance to origin (handles scale ambiguity); confidence-aware loss Σ C·ℓ_regr − α log C, C = 1 + exp(c) > 1; ill-defined points (sky, translucent) get low confidence; learned without explicit confidence supervision.
- 3.3 downstream: matching = mutual nearest neighbours in 3D pointmap space; focal: assume centred principal point & square pixels, f* = argmin Σ C ||(i',j') − f (X0,X1)/X2|| (Weiszfeld); relative pose: Procrustes alignment of X^{1,1}↔X^{1,2} (closed form, scaled σ[R|t]; sensitive to noise) or more robust RANSAC + PnP; absolute pose (visual localisation) via PnP-RANSAC.
- 3.4 global alignment: connectivity graph (retrieval or pass all pairs, ≈25 ms per pair on H100, overlap from average confidence); optimise world pointmaps χ, per-pair pose P_e and scale σ_e: argmin Σ_e Σ_v Σ_i C ||χ − σ_e P_e X||; constraint Π σ_e = 1 (avoid trivial σ=0); can parametrise χ via K, P, depth to recover all cameras; init via max spanning tree; minimises 3D projection errors (not 2D reprojection like BA) → fast, plain gradient descent.
- 4.5 DTU zero-shot MVS without known cameras: accuracy 2.7 mm, completeness 0.8 mm, overall 1.7 mm; below best methods which use GT poses, train on DTU, sub-pixel triangulation; regression less accurate; trade-off: plug-and-play, no camera priors.
- Conclusion: novel paradigm: 3D reconstruction in the wild without prior info about scene or cameras; unifies many 3D vision tasks.
