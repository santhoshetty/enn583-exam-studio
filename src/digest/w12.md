# W12 Visual representations, retrieval, place recognition (L12, 80pp)
- VPR p5-9: "given an image of a place, has the robot seen it before?"; uses: loop closure detection, kidnapped robot, initial candidates for 6-DoF localisation (PnP) p6. Why not GNSS p7: GPS-denied (indoor, underground), NLOS & multipath (urban canyon), canopy, accuracy needs. VPR = instance of image retrieval.
- Image retrieval p10: query -> most similar database images by comparing feature representations; "similar" = same physical place despite appearance/viewpoint change. Representation learning is the task p11.
- Why retrieval not classification p13-16: classification needs fixed place classes, retraining for new places, gives label not ranking; retrieval stores examples, new places by inserting references, returns ranked candidates, scales to large changing sets; nearby places aren't discrete classes (graded similarity).
- Overview p19-27: reference/map/database traverse vs query traverse; can be built simultaneously online. Pixel-wise difference bad (viewpoint/illumination). Similarity matrix (query × database; e.g. 0.99, 0.98 = matches) or distance matrix; threshold θ to declare match. Patterns p29-31: diagonal for same-route sequence; loops etc.
- Single-session (DB = query, both growing; loop closures) vs multi-session (DB yesterday constant, query today growing) p32-33. Scenarios p34-37: candidate selection for expensive 6-DoF localisation; loop closure in SLAM; relocalisation/kidnapped; multi-session & multi-robot mapping (merge maps). Taxonomy: online/batch × single/multi session; DB grows vs constant.
- Challenges p38-43: viewpoint, dynamic scenes/occlusion, illumination/weather (SeqSLAM sunny summer / stormy winter), seasons (3000 km Nordland), perceptual aliasing (different places look alike).
- Evaluation p46-51: GT matches -> binary classification; precision = TP/(TP+FP) (100 matches, 65 correct -> P=0.65); recall = TP/GTP (GTP = queries with a GT match; 100 correct of 200 -> 0.5). PR curve by varying θ; other: max recall at 100/99/95% precision, AUPRC, max F1 = 2PR/(P+R). Recall@K (W8): fraction of queries with at least one correct match in top-K retrieved.
- Descriptors p53-67: global/holistic (one vector; compact, fast retrieval; may lose spatial info, struggles with viewpoint) vs local (set of vectors; preserve local structure, robust to partial overlap/viewpoint, expensive matching). Handcrafted global: Gist, BRIEF-Gist (Sünderhauf & Protzel 2011); CNN features as global descriptor (Sünderhauf et al. IROS 2015). Local: Bag of Visual Words (Video Google, Sivic & Zisserman 2003): cluster descriptors into vocabulary, histogram of words, compare. TF-IDF p63: t_i = (n_id/n_d) · log(N/n_i) (n_id occurrences of word i in doc d; n_d words in doc d; N docs; n_i "how often word i appears across all documents" — standardly number of docs containing word i). Example N=1000, n_d=100: w1 10 in image, 100 overall -> 0.1·log(10); w2 10 in image, 10,000 overall -> 0.1·log(0.1) (negative/low) -> common words less informative. ConvNet landmarks (RSS 2015) local. Aggregation p66: rich local features aggregated into one compact global descriptor; NetVLAD learns aggregation. Modern p67: image -> pretrained ViT/foundation model -> patch descriptors -> aggregation -> global descriptor -> nearest-neighbour retrieval (AnyLoc).
- Learning descriptors p69-75: same place close, different far. Options p72: pretrained representation without VPR training (ImageNet CNNs; DINO); metric/contrastive (contrastive, triplet, InfoNCE); place classification training (CosPlace). Triplet loss: anchor, positive, negative; pull positives, push negatives (e.g. max(0, d(a,p) − d(a,n) + m)). Challenges p75: negatives not too easy/hard; how far is a "new" place; GPS distance defines pos/neg; viewpoint -> geographically close but look different; hard-negative mining.
- p77-80: VPR is first step (candidate generation) -> geometric verification / sequence info (SeqSLAM: match sequences, exploits temporal coherence — difference to plain retrieval). Choose method: invariances needed, precision vs recall, online vs batch, runtime.
- Cosine similarity: cos = qᵀa/(|q||a|); unit vectors -> dot product; opposite vectors -> −1.
- Exam: Q35 qᵀa=1, qᵀb=−1; Q36 recall@2 = 2/5 = 0.4 (ranks 2 and 1 within top-2); Q37 global descriptors for candidates, rerank with local spatial evidence, geometric consistency.
## AnyLoc (Keetha, Mishra, Karhade et al., RA-L 2023 / arXiv 2308.00688, P12)
- Motivation: best VPR methods are environment- and task-specific (urban driving); performance degrades severely in unstructured environments; "universal" = works anywhere (urban, indoor, aerial, underwater, subterranean, degraded), anytime (day–night, seasons), anyview (incl. >90° / opposing viewpoints) WITHOUT re-training or fine-tuning.
- Features: off-the-shelf self-supervised foundation models (DINO, DINOv2; also CLIP compared); DINOv2 ViT-G, dense per-pixel (patch) features from layer 31, value facet (highest contrast; key/query facets have positional bias). Per-pixel features + aggregation beat per-image CLS features.
- Aggregation (unsupervised): F_G = (Σ f_i^p)^{1/p}: p=1 GAP, p=3 GeM, p→∞ GMP; VLAD hard & soft: cluster database features (k-means) into N centres = vocabulary; F_Vk = Σ α_k(f_i)(f_i − c_k) residual sums; intra-normalisation, concatenation, inter-normalisation.
- Domains: PCA projection of DINOv2-GeM global descriptors reveals distinct domains (Urban, Indoor, Aerial, SubT, Degraded, Underwater); queries project near their database -> build domain-specific VLAD vocabularies (+6% improvement). MixVPR (VPR-trained) features collapse to a small region of feature space.
- Evaluation: 12 datasets structured & unstructured (e.g. Pitts-30k, Oxford RobotCar, St Lucia, Baidu Mall, Gardens Point, 17 Places, Hawkins, Laurel Caverns, Nardo-Air, VP-Air, Mid-Atlantic Ridge); metric Recall@1 (also R@5); up to 4× higher Recall@1 than supervised SOTA baselines (NetVLAD, CosPlace, MixVPR) on unstructured sets; radar chart.
- Tutorial optional: is "universal" justified? Not tested e.g. extreme weather, thermal cameras, agricultural/forest, dynamic crowds, very large-scale databases (runtime of ViT-G/VLAD), long-term structural change.
