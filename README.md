# ENN583 Exam Studio

Single-page exam-prep site for QUT ENN583 Foundations of Robotic Vision: 13 topic tabs (explanations, worked examples, interactive widgets, mini-quizzes, paper summaries), a mock exam, practice Q&A and a two-page cheatsheet (`cheatsheet.pdf`).

- `index.html`: the built site (no build step needed to view).
- `src/`: build scripts (`build.py`), content modules (`frag/`), weekly digests (`digest/`), number checks (`checks/`) and browser tests.

Course lecture PDFs, tutorial papers and the practice exam PDF are **not** included in this public repository (copyright), so the in-page notes viewer cannot open them here.
